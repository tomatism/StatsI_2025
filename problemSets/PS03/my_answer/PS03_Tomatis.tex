\section*{Question 5}
\noindent What if the incumbent's vote share is affected by both the president's popularity and the difference in spending between incumbent and challenger? 
	\begin{enumerate}
		\item Run a regression where the outcome variable is the incumbent's \texttt{voteshare} and the explanatory variables are \texttt{difflog} and \texttt{presvote}.	\vspace{0.5cm}
		\item Write the prediction equation.	
		\vspace{0.5cm}
		\item What is it in this output that is identical to the output in Question 4? Why do you think this is the case?
	\end{enumerate}

\vspace{2.5cm}

\noindent\textbf{Answer 5.1}\\

\vspace{0.5cm}
\noindent Differently from before, a multivariate linear regression is now run. The dependent variable is \texttt{voteshare}, while both \texttt{presvote} and \texttt{difflog} are used as explanatory variables. This fifth regression allows for controlling differences in spending between the incumbent’s and challenger’s parties when estimating the effect of the presidential candidate’s vote share on the overall incumbent party’s vote share, and vice versa. In simpler terms, the coefficients obtained from this regression can be interpreted as the effect of each explanatory variable on the dependent variable, holding the other independent variable constant.

\]

\vspace{1cm}
\noindent\textbf{Answer 5.3}\\

\vspace{0.5cm}
\noindent The $\hat{\beta}_1$ coefficients are identical in the bivariate residuals regression estimated in Question 4 and in the multivariate regression run in Question 5. This occurs because the residuals obtained in Questions 1 and 2 represent the remaining variation in \texttt{voteshare} and \texttt{presvote} after controlling for \texttt{difflog}. Regressing one set of residuals on the other therefore captures the extent to which the unexplained variation in one variable is associated with that in the other. This is the same underlying mechanism as in a multivariate regression, where each explanatory variable’s coefficient is estimated while holding the others constant, thereby controlling for their effects.
\noindent The $\hat{\beta}_1 = 0.257$ coefficient is interpretable as the expected average change in incumbent's party overall vote  hare given a unital change in incumbent's party presidential candidate's vote share, keeping the difference in spending between parties constant.
